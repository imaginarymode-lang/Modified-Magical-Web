# Magical Circle - Arcane Landing Page

A custom-built, mystic-themed interactive landing page inspired by web design tutorials and re-imagined with custom spellcraft aesthetics, glowing animations, and dark-mode styling.

## 🌟 Features
- **Mystic Eldritch Mandala:** Animated rotating magical aura behind the main hero image.
- **Glassmorphic Spell Cards:** Floating elements with custom icons and dark glowing borders.
- **Responsive Design:** Fully adapted layout for mobile, tablet, and desktop viewports.
- **Custom Theme:** Arcane/Spellcraft color palette, typography, and interactive UI elements.

## 🛠️ Built With
- **HTML5**
- **CSS3** (Flexbox, CSS Grid, Custom Variables, `@keyframes` Animations)
- **JavaScript**
- **Remixicon / FontAwesome** (Icons)

## 🙏 Credits & Inspiration
This project was inspired by the web design tutorial [How To Build Landing Page Using HTML CSS And JavaScript](https://www.youtube.com/watch?v=99VV8wnO2Kc&list=PLz_5rPRIvGEBDvyf-HIIDHjsPppnuXtFG&index=6) on YouTube. 

The original template was modified, re-themed, and custom-styled into a original magic/arcane experience.
